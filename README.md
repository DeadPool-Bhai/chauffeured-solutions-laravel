# Chauffeured Solutions (Laravel)

Laravel 12 rebuild of chauffeuredsolutions.com.au, migrated from WordPress with URLs, copy, headings and meta data kept identical (Phase 1).

- Plan and findings: [docs/migration-plan.md](docs/migration-plan.md)
- Stack: Laravel 12, Blade, Tailwind, Alpine.js, Filament admin
- Hosting target: Hostinger Cloud (database queue and cache, cron every minute)

Branches: `main` matches what is live. Work happens on `develop` and arrives by pull request.
